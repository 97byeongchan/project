Introduction

RelFlexformers provide a new class of efficient 3D Transformers that combine expressive relative positional encodings with subquadratic attention. By framing geometric modulation via the Non-Uniform Fourier Transform, we have shown that it is possible to incorporate a broad family of integrable RPE functions without sacrificing the computational benefits of kernelized attention. Our approach achieves a complexity of $O(L \log L)$, establishing it as a highly scalable architecture for processing large-scale, irregular point clouds that were previously bottlenecked by the quadratic cost of standard dense attention. Our empirical results across various 3D benchmarks demonstrate that the flexibility provided by our framework, specifically the ability to handle non-structured, heterogeneous token distributions, leads to consistent performance gains over the baseline Performer and even surpassing the dense Transformers.

Motivation

Relative positional encodings are essential for 3D perception because the geometry between tokens carries important information. However, standard dense attention is quadratic in the sequence length, while efficient kernelized attention usually avoids materializing the full attention matrix. This makes it difficult to directly apply expressive pairwise RPE masks.

Dense Transformer

Can naturally use pairwise relative positional encodings, but requires full $L \times L$ attention computation.

Geometry-aware, but expensive.

Performer

Uses kernelized attention to reduce attention cost, but does not directly expose the full attention matrix for arbitrary pairwise RPE modulation.

Efficient, but less flexible for RPE.

RelFlexformer

Keeps the efficient attention structure while applying a flexible RPE mask through a fast NU-FFT-based operator.

Efficient and geometry-aware.

Key Idea

RelFlexformer represents relative positional encoding as a modulation function over relative 3D coordinates. For token coordinates $r_i$ and $r_j$, the RPE mask is written as

$$M_{ij}=f(r_i-r_j),$$ where $f$ is an integrable modulation function that determines the geometric attention bias.

Directly constructing $M$ is quadratic. Instead, RelFlexformer treats multiplication by $M$ as a fast operator. Given a vector $u$, it computes $Mu$ using a Fourier-domain representation and the Non-Uniform Fast Fourier Transform.

1

Forward NU-FFT

Map values defined on non-uniform 3D token coordinates into the frequency domain.

→
2

Frequency modulation

Multiply by the Fourier transform of the chosen relative positional encoding function.

→
3

Inverse NU-FFT

Return to the token domain and obtain the RPE-modulated mask-vector product.

$$Mu \approx \mathrm{NUFFT}^{-1}\left(\mathcal{F}(f)\cdot \mathrm{NUFFT}(u)\right).$$

The important point is that RelFlexformer does not need to explicitly store the full RPE mask. It only needs to apply the mask as an operator inside efficient attention.

Flexible Relative Positional Encodings

A key advantage of RelFlexformer is that the modulation function $f$ can be chosen to express different geometric priors. This makes the framework more general than using a single fixed positional encoding rule.

Distance decay

Encodes the intuition that nearby 3D tokens should interact more strongly than distant tokens.

Oscillatory bias

Allows sinusoidal or sinc-like modulation patterns that resemble Fourier positional encodings.

Learnable geometry

The modulation function can be adapted to the target task and data distribution.

$$\text{Different choices of } f \quad \Rightarrow \quad \text{different geometry-aware attention biases.}$$

Relation to Existing Positional Encodings

RelFlexformer can be viewed as a unifying framework for relative positional modulation. RoPE-like harmonic modulation and STRING-style projection-based modulation can be interpreted as special cases within this broader Fourier-operator perspective.

RoPE-style

Harmonic relative modulation can be represented through frequency components.

STRING-style

Projection-based cosine modulation can be handled as a structured choice of $f$.

Distance kernels

Radial or decay-based kernels can encode locality in 3D space.

RelFlexformer

Generalizes these ideas to flexible integrable RPE functions on irregular tokens.

Results

RelFlexformer is evaluated across object classification, 3D semantic segmentation, and RGB-D semantic segmentation. The main empirical message is that flexible RPE substantially improves Performer-style efficient attention and often closes the gap to dense attention.

Efficiency

Additional Analysis

Effect of Quadrature Size

The quadrature size $S$ controls the approximation quality of the Fourier-based mask-vector multiplication. Increasing $S$ generally improves the approximation, but the best value is task-dependent and often saturates.

Small $S$

Lower computational cost, but weaker approximation of the RPE operator.

Moderate $S$

Often enough to recover most of the benefit from flexible relative positional encoding.

Large $S$

More accurate approximation, but may provide diminishing returns depending on the task.

Plug-in Backbones

RelFlexformer is not tied to a single architecture. It can be integrated into multiple 3D perception backbones by replacing or augmenting their efficient attention blocks.

PCT

Used for object classification on ModelNet40 and ScanObjectNN.

PTv3

Used for point cloud semantic segmentation on large-scale 3D datasets.

DFormer

Used for RGB-D semantic segmentation on NYU Depth v2 and SUN RGB-D.

Scope

RelFlexformer is designed to recover geometry-aware attention in efficient Transformer settings. Dense softmax attention can still be competitive on some benchmarks, but RelFlexformer significantly improves Performer-style attention while preserving subquadratic scalability.

Conclusion

RelFlexformer provides an efficient and flexible way to incorporate relative positional encodings into 3D Transformers. By formulating the RPE mask as a Fourier-based operator, it avoids explicit quadratic mask construction while supporting irregular 3D token configurations. This makes it a practical approach for scalable point cloud and RGB-D perception.

Expressive RPE

Uses integrable modulation functions to encode flexible geometric relations.

Subquadratic Scaling

Applies RPE masks through NU-FFT-based computation in $O(L \log L)$.

Broad Validation

Demonstrates gains across object classification, 3D segmentation, and RGB-D segmentation.
